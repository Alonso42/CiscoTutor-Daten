# CiscoTutor-Daten

Fragen und Lektionen für **CiscoTutor – Die Jagd nach dem Heiligen Zertifikat**.
Die App lädt beim Start `daten/version.json` und holt sich neuere `fragen.json` / `lektionen.json` automatisch – ohne neue APK.

Diese Dateien werden automatisch aus dem (privaten) Entwicklungs-Repo erzeugt (`CiscoTutor/tools/daten_veroeffentlichen.sh`). Bitte nicht von Hand bearbeiten.
